# Ricoh IM C3510 PostScript driver (PPD)

`Ricoh-IM_C3510_PS.ppd` is Ricoh's own PPD, unchanged, from OpenPrinting's
foomatic-db:
https://github.com/OpenPrinting/foomatic-db/blob/master/db/source/PPD/Ricoh/PS/Ricoh-IM_C3510_PS.ppd

Copyright Ricoh Company, Ltd., released under the MIT license (see the
header of the file). It needs the `foomatic-rip` filter, which comes with
Ubuntu's `cups-filters` package.
